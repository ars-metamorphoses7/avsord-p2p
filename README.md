JUMP é basicamente o Discord que caiu de cabeça no Windows 98, tomou café demais e decidiu virar P2P: você cria uma sala, chama seus amigos e troca mensagens, arquivos, áudio, câmera e tela diretamente entre os computadores via WebRTC, enquanto o servidor só ajuda a galera a se encontrar — histórico fica local no IndexedDB (até ~500 MB/50 mil mensagens por conversa), arquivos vão em blocos P2P (até 200 MB) e ninguém precisa criar conta nem entregar o histórico para um servidor central; para brincar no navegador rode `npm install` e `npm run dev`, para a experiência completa use a release desktop (Windows ou Linux), conecte todo mundo na mesma rede/Radmin VPN, abra o JUMP no host com `npm run desktop`, permita as portas `8787`/`5173` no firewall e envie um convite `jump://join?signal=http%3A%2F%2FIP-RADMIN%3A8787&room=ID-DA-SALA`, lembrando que isso ainda é uma criatura alpha com estética de janela cinza, então se algo parecer estranho respire fundo, confira se os dois estão na mesma VPN e tente de novo; releases e instaladores moram em [ars-metamorphoses7/avsord-p2p](https://github.com/ars-metamorphoses7/avsord-p2p).
